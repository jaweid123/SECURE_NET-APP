# 📖 Overview

**SecureNet Inspector** is a modern and professional desktop application designed for **network security analysis**, **system monitoring**, and **basic cybersecurity auditing**.

The toolkit helps security professionals, students, and network administrators quickly analyze devices, scan open ports, monitor system performance, and generate detailed security reports.

Built with Python and optimized for simplicity, speed, and usability.

---

# ✨ Key Features

| Feature | Description |
|----------|-------------|
| 🔍 **Advanced Port Scanner** | Multi-threaded TCP port scanning with fast and accurate results |
| 🌐 **Network Discovery** | Detect active hosts and devices connected to the local network |
| 📊 **Real-Time System Monitor** | Monitor CPU, RAM, Disk, and Network usage live |
| 📄 **Professional PDF Reports** | Generate clean and detailed security assessment reports |
| 💾 **Export Functionality** | Export scan results to JSON, CSV, or TXT formats |
| 🌓 **Dark & Light Themes** | Modern UI with theme switching support |
| ⚡ **Quick Scan Mode** | Scan the most common ports instantly |
| 🛡️ **Security Recommendations** | Receive automatic security suggestions based on findings |
| 📋 **Clipboard Support** | Copy results instantly with one click |
| 🖥️ **Cross-Platform Support** | Compatible with Windows, Linux, and macOS |

# 🚀 Installation

## Option 1 — Windows Installer (Recommended)

1. Download the latest installer from the Releases section
2. Run `SecureNet_Inspector_Setup.exe`
3. Follow the installation wizard
4. Launch the application from Desktop or Start Menu

---

## Option 2 — Run from Source Code

### 📌 Requirements

- Python 3.10+
- pip package manager

---

### 🔧 Installation Steps

```bash
# Clone repository
git clone https://github.com/jaweid/SecureNet-Inspector.git

# Open project folder
cd SecureNet-Inspector

# Install dependencies
pip install -r requirements.txt

# Run application
python main.py
````
